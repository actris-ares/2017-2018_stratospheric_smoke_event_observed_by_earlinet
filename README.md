# The unprecedented 2017–2018 stratospheric smoke event: decay phase and aerosol properties observed with the EARLINET

> This repository is archived. The dataset is published on Zenodo with DOI
> [10.57837/actris-ares/7zvn-y190](https://doi.org/10.57837/actris-ares/7zvn-y190):
> please cite it and download it from there. The content below is kept unchanged for reference.

This dataset provides information related to the paper "The unprecedented 2017–2018 stratospheric smoke event: decay phase and aerosol properties observed with the EARLINET". It includes six months of stratospheric aerosol observations collected by the European Aerosol Research Lidar Network (EARLINET) from August 2017 to January 2018.

Baars, H. et al.: The unprecedented 2017–2018 stratospheric smoke event: decay phase and aerosol properties observed with the EARLINET, Atmos. Chem. Phys., 19, 15183–15198, https://doi.org/10.5194/acp-19-15183-2019, 2019.
